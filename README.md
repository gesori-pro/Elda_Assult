# Elda Assault

MapleStory Worlds에서 제작 중인 3라인 동시 배치형 PvE 전략 게임 프로젝트입니다.  
기획 단계의 작업명은 **Three Lane Nexus**입니다.

## 게임 개요

- 플레이어와 적이 세 개 라인에 몬스터를 동시에 비공개 배치합니다.
- 배치가 끝나면 양측 편성이 공개되고 자동 전투가 진행됩니다.
- 같은 라인의 최전방 적을 먼저 공격하며, 적이 없으면 상대 수호석으로 전진합니다.
- 수호석 체력은 30이며 먼저 상대 수호석을 파괴하면 승리합니다.
- 코스트를 즉시 사용할지 저장해 고코스트 몬스터로 역전할지가 핵심 선택입니다.

## 현재 개발 범위

- PvE M1 우선 개발
- 스토리 모드와 봇전 난이도 하/중/상
- 3라인 × 진영별 15개 배치 슬롯
- PC 가로 화면 우선, 모바일 가로 화면 필수 대응
- 1차 밸런스 검증용 고유 몬스터 7종

## 저장소 구조

| 경로 | 내용 |
|---|---|
| `RootDesk/MyDesk/ThreeLaneNexus/` | 게임 로직과 HUD mLua |
| `RootDesk/MyDesk/Models/ThreeLaneNexus/` | 프로젝트 전용 모델 |
| `map/` | 프로토타입 맵 |
| `ui/` | 프로토타입 HUD |

`.mlua`와 연결되는 `.codeblock`은 Maker가 관리하는 등록 정보이므로 직접 편집하지 않습니다.

## 공개 범위

이 저장소에는 프로젝트에서 직접 작성한 구현 파일만 포함합니다. 내부 기획 문서, API 키, 로컬 도구 설정, MSW 기본 엔진 파일과 추출 리소스는 포함하지 않습니다.

## 프로젝트 성격

이 저장소는 MapleStory Worlds에서 제작 중인 개인 게임 프로젝트입니다. MapleStory와 관련된 상표, 캐릭터 및 원저작물의 권리는 각 권리자에게 있습니다.
